# PCE-Space-Adventure-Cobra-II-Kr

**스페이스 어드벤처 코브라 II — 전설의 사나이 · 비공식 한국어 패치 v0.8**

PC Engine Super CD-ROM²용 일본판 **Space Adventure Cobra II - Densetsu no Otoko (Japan)**의 한국어 검수판입니다. 장면을 조사하고 인물과 대화하며 진행하는 SF 어드벤처에 한글 대사·선택지와 게임 내부 음성 자막을 적용했습니다.

**한글화: 기타 깎는 노인** · **배포일: 2026-10-30**

## 다운로드

**[v0.8 릴리스 및 다운로드](https://github.com/OldManCraveGuitars-bit/PCE-Space-Adventure-Cobra-II-Kr/releases/tag/v0.8)** · **[Windows 패처 ZIP](https://github.com/OldManCraveGuitars-bit/PCE-Space-Adventure-Cobra-II-Kr/releases/download/v0.8/PCE-Space-Adventure-Cobra-II-Kr-v0.8.zip)**

ZIP에는 Python 설치 없이 사용하는 Windows EXE 패치 적용기, 원본 선택 창, 차이 패치, 사용법 및 SHA-256 목록을 넣었습니다. 원본 게임·BIOS·완성된 게임 이미지는 포함하지 않습니다. ZIP 전체를 압축 해제한 뒤 사용하세요.

## 한글화 내용

- 본문 원장 5,044개 중 4,990개를 검토 번역으로 반영했습니다. 코드·중복 경계 54개는 제외했습니다.
- 추가 음성 자막 1,024개를 편집 검토 상태로 반영했습니다. 오프닝의 기존 스프라이트 자막 18개도 한글화했습니다.
- 타이틀·부제·작가명·메뉴와 일본어 엔딩 크레딧 89개 필드를 한글화했습니다. 크레딧의 영문 9개 필드는 보존했습니다.
- 12×12 한글, 6픽셀 공백과 줄별 중앙 정렬을 적용했습니다. 추가 자막은 게임 내부에서 음성 이벤트에 맞춰 표시합니다.
- 원래 영문, 그림, 음악, 음성을 보존합니다. 타이틀 오른쪽 반짝임도 유지합니다.

## v0.8 수정 내용

- 추가 자막 1,024개(중복 제외 일본어·한국어 945쌍)와 오프닝 자막을 다시 읽고 문장·용어·띄어쓰기 14곳을 수정했습니다.
- `가지 말려 봐야`를 `말려 봐야`로 고치고, `기관실`, `최종 병기`, `최고 평의회`, `에어 바이크` 표기를 정리했습니다. 터틀호·문신·엔진 손상·크리스털 보이 대사의 문장도 다듬었습니다.
- 술집 건물 앞 첫 자막 **“저거로군.”**의 시작 시각은 유지하고 표시 시간을 **0.89초 → 2.17초**로 늘렸습니다.
- 원음 발음이 불명확했던 짧은 놀람과 앵무새의 욕설은 문맥에 맞게 의역했습니다. 정확한 일본어 발음까지 확정한 것으로 표시하지 않습니다.

## 적용 방법

1. **일본판 원본 CUE와 9개 BIN**을 한 폴더에 준비합니다. 지원하는 원본의 크기·해시는 [HASHES.md](HASHES.md)에서 확인하세요.
2. 패처 ZIP 전체를 새 폴더에 풉니다. `data`, `build` 폴더를 포함한 구성을 유지합니다.
3. **`패치 적용.cmd`를 더블클릭**하고 원본 CUE를 선택합니다. CUE를 CMD 위에 끌어 놓아도 됩니다.
4. 선택 창으로 실행하면 원본 폴더 옆에 `원본 폴더명 [KO v0.8]`이 생깁니다. 끌어 놓기로 실행하면 기본 이름은 `[KO-preview]`입니다. 기존 결과 파일은 덮어쓰지 않습니다.
5. 출력된 **`cobra2-ko-experimental.cue`**를 실행합니다. 모든 출력 BIN과 CUE를 같은 폴더에 둡니다.

**Super CD-ROM² System Card 3.0**이 필요합니다. 출력 공간은 약 400MiB 이상 확보하세요. v0.8의 입력 형식은 지원 매니페스트와 일치하는 분할 BIN/CUE입니다. CHD·단일 BIN과 다른 덤프는 직접 입력으로 지원하지 않습니다.

원본 CUE 자체의 파일명과 폴더 위치는 바뀌어도 됩니다. CUE 내용의 SHA-256 및 참조하는 9개 BIN의 파일명·크기·SHA-256은 지원 원본과 같아야 합니다. 이미 패치한 게임에 덧씌우지 않습니다.

### 명령줄

```bat
Cobra2PatchApplier.exe "D:\원본\원본.cue" "D:\코브라2 한글 v0.8"
Cobra2PatchApplier.exe "D:\원본\원본.cue" --verify-only
Cobra2PatchApplier.exe "D:\원본\원본.cue" "D:\코브라2 한글 v0.8" --link-audio
```

`--verify-only`는 결과 데이터 해시까지 계산하고 출력 파일을 만들지 않습니다. `--link-audio`는 같은 드라이브의 음성 트랙을 하드링크로 공유하여 추가 복사를 줄입니다. 공유한 음성 파일은 직접 편집하지 마세요. 기본 적용은 별도 복사입니다. 소스로 실행할 때는 Python 3.11 이상에서 `python tools/apply_patch.py 원본.cue 출력폴더`를 사용합니다.

### 실행 및 저장

새 판은 에뮬레이터를 완전히 재시작한 뒤 실행하세요. 이전 판의 상태 저장(`.state`, MCS 등)은 당시 코드도 복원할 수 있으므로 새 판에 불러오지 않습니다. 게임 안의 LOAD로 진행을 이어갈 수 있으며 에뮬레이터의 저장 파일 이름·위치는 사용 환경에 맞춰야 합니다. 기존 게임 저장과 상태 저장은 보관하세요.

## 검수 범위와 알려진 제한

v0.8은 **검수판**입니다. Mednafen과 RetroArch 1.22.2 / Beetle PCE FAST v1.31.0.0의 실행을 확인했습니다. 술집 앞 자막은 기존 판에서 54프레임, 수정판에서 130프레임 표시됐으며, 실제 RetroArch 화면에서도 연장된 표시를 확인했습니다. 사용자가 신고한 완전 미표시는 기본 설정에서 재현되지 않아 해당 환경의 원인까지 해결했다고 표시하지 않습니다.

추가 자막의 편집 검토와 설치된 자막의 실행 근거는 정리했지만, 전체 스토리의 모든 분기·모든 프레임·실기·사람의 전 음성 청취를 완료한 것은 아닙니다. 본문 4,990개의 의미를 이번 재검수에서 다시 전수 대조한 것으로 표시하지 않습니다. 일부 그림의 실제 사용 여부 및 일부 혼합 음성의 본편 호출은 확인이 남아 있습니다. [상세 검수 범위](QA.md) · [변경 내역](CHANGELOG.md)

## 해시와 구성요소

원본 CUE/BIN, 패치 적용 결과, 차이 패치 및 EXE의 SHA-256은 [HASHES.md](HASHES.md)에 기록했습니다. 다운로드 파일의 해시는 릴리스의 `SHA256SUMS.txt`로 확인할 수 있습니다. 빌드의 논리 데이터 SHA-256과 개별 BIN 해시는 서로 다른 대상입니다.
