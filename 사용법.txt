스페이스 어드벤처 코브라 II 한국어 검수판 v0.8 (5657193d)

Windows 사용법
1. ZIP 전체를 압축 해제합니다. data와 build 폴더를 유지하세요.
2. '패치 적용.cmd'를 더블클릭한 뒤 원본 일본판 CUE를 선택합니다.
3. 원본 폴더 옆의 '[KO v0.8]' 폴더에서 cobra2-ko-experimental.cue를 실행합니다.
   CUE를 CMD에 끌어 놓으면 기본 출력 폴더 이름은 '[KO-preview]'입니다.
4. Super CD-ROM2 System Card 3.0이 필요합니다. Python 설치는 필요 없습니다.

지원 원본은 9개 BIN + CUE입니다. CHD·단일 BIN·다른 덤프는 직접 입력으로 지원하지 않습니다.
원본 파일 크기와 SHA-256은 HASHES.md를 확인하세요. 기존 출력 파일은 덮어쓰지 않습니다.
이전 판의 상태 저장(.state/MCS)을 새 판에 불러오지 말고 게임 안의 LOAD로 진행을 이어갑니다.
기존 저장 파일은 보관하세요. 새 게임 실행은 에뮬레이터를 완전히 재시작하여 확인합니다.

명령줄:
Cobra2PatchApplier.exe "D:\원본\원본.cue" "D:\코브라2 한글 v0.8"
Cobra2PatchApplier.exe "D:\원본\원본.cue" --verify-only
같은 드라이브에서 --link-audio를 추가하면 음성 BIN 추가 복사를 줄입니다. 공유 파일을 편집하지 마세요.

추가 음성 자막 1,024개, 본문 검토 번역 4,990개, 타이틀·오프닝·크레딧 한글화.
문장·용어·띄어쓰기 14곳 수정, 술집 앞 첫 자막 0.89초→2.17초 연장.
원래 영문·그림·음악·음성과 타이틀 오른쪽 반짝임을 보존합니다.
전체 분기·실기·전 음성 청취가 끝난 완성판은 아닙니다. 상세 범위는 QA.md를 보세요.
술집 앞 완전 미표시 신고는 기본 RetroArch/Beetle PCE FAST 조건에서 재현되지 않았습니다.
원음이 불명확한 두 문구는 문맥에 맞게 의역했습니다.
